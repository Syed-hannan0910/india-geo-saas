2. Search villages with autocomplete:

API Reference

Base URL: https://api.india-geo.io/api/v1  ·  Auth: X-API-Key header
Endpoints
📍 States 🏛️ Districts 📌 Sub-Districts 🏘️ Villages 🔍 Search
GET/states
Returns all 30 Indian states. Cached 24h at edge.
Response 200 { "data": [ { "id": 1, "code": "01", "name": "Andhra Pradesh" }, ... ], "meta": { "count": 30 } }
GET/states/:id
Single state with district count.
GET/districts?state_id=1
All districts for a state. state_id required.
GET/districts/:id
Single district with sub-district count.
GET/sub-districts?district_id=1
All sub-districts (taluks/tehsils/blocks) for a district.
GET/villages?sub_district_id=1&page=1&limit=200
Paginated village list. Max 500 per page. Served from materialized view — typically <15ms.
Response 200 { "data": [ { "id": 12345, "code": "100234", "name": "Dhule", "full_address": "Dhule, Dhule, Dhule, MAHARASHTRA, India" } ], "meta": { "total": 423, "page": 1, "pages": 3 } }
GET/villages/code/:plcn
Lookup village by 6-digit Census MDDS PLCN code.
GET/search?q=mumbai&type=village&state_id=&limit=10
Fuzzy search with trigram similarity. Handles typos. Scoped to state or district optionally.
ParamTypeDescription
qstringSearch term (min 2 chars)
typeenumvillage | sub_district | district | state | all
state_idintegerScope to a specific state
district_idintegerScope to a specific district
limitintegerMax results (capped by plan)
Rate-limit headers returned on every request: X-RateLimit-Limit-Minute: 60 X-RateLimit-Remaining-Minute: 58 X-RateLimit-Limit-Day: 50000 X-RateLimit-Remaining-Day: 49821
